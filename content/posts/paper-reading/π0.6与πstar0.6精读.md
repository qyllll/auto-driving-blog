## 🧒 小白 3 分钟：什么叫「优势条件化」？

模仿学习的死穴：**机器人自己跑部署时会犯小错**（抓偏 2cm、碰倒杯子），错完环境就进入「演示里没见过的状态」，模型越走越偏——这就是经典的分布偏移问题（DAgger 一脉要解决的老问题）。

正统 RL 解法（PPO 等）要**策略梯度**：好动作概率↑、坏动作↓。但大 VLA 上直接 PPO 又贵又不稳（见[具身 RL 调研](/posts/paper-reading/具身智能强化学习调研精读/)的 iRe-VLA/VLA-RL 节）。

RECAP 的巧思：**不改损失函数，改输入**——
1. 训一个**价值函数**，给每一步打「离成功还差几步」的分；
2. 把分数**二值化**成一个指示位 `I_t ∈ {好, 坏}`，**像语言一样拼进 VLA 的输入条件**；
3. 然后用**普通监督学习**在全部数据（好坏都要！）上训练——模型自己学会「当条件说这步是坏的，就输出不那么坏的动作」。

一句话：**把「学强化学习」变成「学会听一个好坏提示」**——梯度消失在监督里，RL 的信号活在条件里。这也是为什么坏数据不再需要扔掉：带「坏」标签的样本反而教会模型纠错方向。

## 🧠 RECAP 框架与原理（本文重点）

### 4.1 问题设定

模仿策略 π 部署时产生**偏离演示分布**的状态；专家纠正（遥操作接管）和自主成功/失败都是**免费的奖励信号源**，但怎么让 5B 级 flow-matching VLA 稳定吸收它们是工程难点。

### 4.2 价值函数：给「剩余步数」打分

- **架构**：与 π\*0.6 策略同构（同样的语言输入通道），但 **VLM backbone 更小**——批评家比演员便宜；
- **目标**：预测**距成功的剩余步数**并按任务最大长度归一化（成功轨迹映到负值区段，越接近完成越「负得深」）——等价于「进度价值」，比稀疏 0/1 奖励密得多；
- **多任务**：一个价值函数评所有任务（Fig. 4 四任务同框；Fig. 13 扩展到 hang towel/attach hook 等）——红色段=价值下跌（错误发生地），绿色段=价值回升（纠错成功）。

### 4.3 策略提取：优势条件化替代梯度 RL

- 用价值函数对**全部积累数据**（演示、on-policy rollout、干预接管段）逐步算**优势**（相对参考策略的价值提升），**二值化**为指示 `I_t`；
- VLA 输入 = 原条件（语言/图像/本体）**+ I_t**；训练损失 = 标准监督（flow matching）——**好坏样本同锅炒**，靠条件位区分；
- 论文定位：等价于「用优势条件化的监督学习做 on-policy PPO/REINFORCE 的策略提取」——优势信号进了输入而不是损失的梯度；与 AWR 的区别在 AWR 用重要性加权损失+正则行为策略，RECAP 把选择权交给条件（推理时还能用 **CFG（无分类器引导）** 把「好」的方向拧大——附录 A-E，β>1 时测试期还能再涨）。

### 4.4 三段式训练管线（Algorithm 1 骨架）

1. **离线 RL 预训练**：在异构预训练数据上，用价值标签做优势条件化离线 RL → 得到**通才 π\*0.6**（此时已带 I_t 接口）；
2. **任务专项迭代**：选定任务上**机上 on-policy 采数**（+可选专家干预），价值函数标注 → 条件化 SFT 更新策略与价值；
3. **循环**：每轮「采-标-训」为一次 Recap 迭代（i=1,2,…）——**第一轮主要冲成功率，第二轮主要冲吞吐**（Fig. 9/10 的经典形态）。

### 4.5 系统与数据细节

- 预训练含**多机器人站点**数据；子任务命令与异构提示是 π0.6 的条件化资产（Fig. 1 左栏：diverse robotic data / sub-task commands / multimodal web data）；
- 评测协议含 300 episodes × 4 站点等配置（附录）；价值函数可视化覆盖 espresso/box/hang towel/hook（Fig. 13）。

## 🧪 实验总结：两轮分工与对照

1. **阶段叠加（Fig. 7/8）**：offline RL+SFT 基线 → +on-policy 采数 → +专家干预 → 迭代——每个阶段都涨；多样叠衣与 espresso 吞吐翻倍、失败率减半；
2. **两轮分工（Fig. 9/10）**：第 1 轮冲成功率（90%+），第 2 轮冲吞吐；箱组装的「先降后升」是效率-安全权衡的真实轨迹；
3. **方法对照（Fig. 11）**：RECAP ≫ AWR ≫（PPO 系）在叠衣吞吐上——条件化提取完胜梯度提取；
4. **定向排障（Fig. 12）**：严判据变体上两轮迭代即可定点清除失败模式。

## 🌏 辐射章节：从 RECAP 看别人的具身 RL 都怎么做

π 家族这条「优势条件化」支线，放进取景框就是 2025–26 具身 RL 大潮的**一条主脉**。各家思路一张表（详解见[具身智能强化学习调研精读](/posts/paper-reading/具身智能强化学习调研精读/)）：

| 方法 | 打分/信号从哪来 | 怎么进策略 | 与 RECAP 的对照 |
| --- | --- | --- | --- |
| **RECAP（本文）** | 小 VLM 价值函数（剩余步数） | **二值优势拼进输入**，全数据监督 | —— |
| **RL Token（PI, 2026-03）** | 在线 RL 抽出「RL token」 | token 作为快速在线 RL 的接口 | 同厂后续：把 RL 能力**蒸馏成一个 token 通道** |
| **π0.7 的 Recap 蒸馏** | Recap 产出的带元数据经验 | 当预训练数据回灌通才 | RL 从「改模型」变「造数据」 |
| **iRe-VLA** | 任务奖励 | RL 段与 SFT 段**交替**稳大模型 | 同样怕在线不稳，走「间歇式」而非条件化 |
| **VLA-RL** | **VLM 过程奖励模型** | 轨迹级 PPO/GRPO 式 + 向量化环境 | 奖励靠「评委模型」，梯度仍进参数 |
| **RLDG** | 每任务 RL 专家轨迹 | 专家数据**蒸馏**通才 | 与「蒸馏进 π0.7」同构：RL 当数据厂 |
| **ConRFT** | 离线 critic + 在线任务奖励 | 一致性策略桥接两段 | 混合式；RECAP 用条件位替代在线梯度 |
| **BORA** | 离线 IQL critic + 在线残差 | token-动作离线 RL + 真机只学残差 | 同样用 critic；RECAP 全程端到端 VLA |
| **FIND** | 残差离策略 RL + 自评 | 真机自主找题练 | 同「从部署中学」；RECAP 有人类干预源 |
| **SONIC** | 密集动捕跟踪奖励 | PPO，大规模缩放 | 底层控制 RL；与 VLA 后训练互补 |
| **FluxVLA Engine** | reward/advantage-weighted + RLinf 插槽 | 工程框架承接上述任一算法 | RECAP 式算法的「货架化」容器 |

**收束一句**：2025 年的答案是「梯度下不下去就换间歇/蒸馏」（iRe-VLA/RLDG），2026 年的答案开始变成「**信号换通道**」——RECAP 换到条件输入、RL Token 换到专用 token、π0.7 换到数据集；**梯度越来越退居二线，「告诉模型什么好」的方式越来越多元**。

## 💡 评析：三个亮点，三条边界

### 三个亮点

1. **坏数据的哲学翻转**：失败与干预不再是「污染」而是「教材」——只要配得上价值标签与条件位，全部同锅监督；
2. **两轮分工的工程节奏**：先保成功率再抠吞吐——真机 RL 迭代的可复用剧本（箱组装的先降后升尤其诚实）；
3. **家族协同**：π0.6 供基座、π\*0.6 供方法、π0.7 供蒸馏出口——一条数据-方法-产品的完整回路。

### 三条边界

1. **闭源全家桶**：价值函数、干预数据、复现协议都不公开——方法思想可抄，数值难复现；
2. **依赖专家干预**：干预质量=上限；完全自主的「无人纠正」场景要靠后续 FIND 式自评补课；
3. **评测判据在自家任务上**：吞吐/失败率定义与站点布局强绑定，跨论文数字不可直接比。

## ❓ 自测 Q&A

**Q1：π0.6 和 π\*0.6 差在哪？**  
π0.6 是基座（Gemma3 4B 更大脑 + 更多条件化，model card）；π\*0.6 在输入里**多了一个优势指示位**，并用 RECAP 三段管线训完——「能不能听好坏提示」是分界线。

**Q2：为什么不用 PPO 直接训？**  
大 VLA 在线 PPO 不稳且贵（iRe-VLA/VLA-RL 均为证）；RECAP 把优势信号从损失函数挪到输入条件，用监督学习的稳定性吃下 RL 信号，Fig. 11 对照完胜 PPO/AWR。

**Q3：价值函数为什么预测「剩余步数」而不是 0/1 成功？**  
步数是稠密进度信号——红绿价值曲线（Fig. 4/13）能定位错误发生的精确时刻，优势标签才不会全是「最后一步才变好」的垃圾。

**Q4：干预（intervention）是什么？**  
专家在机器人自主执行时**遥操作接管**的片段——机器人自己的前半程 + 专家的后半程拼成「从错误状态回到正轨」的黄金样本（DAgger 血统）。

**Q5：π0.7 还需要 RECAP 吗？**  
训练上不需要——π0.7 用的是**Recap 已蒸馏好的经验数据**（带元数据回灌预训练）；推理侧 π0.7 开箱即有 π\*0.6 级任务表现（论文对照过）。

**Q6：和站内强化学习调研篇什么关系？**  
本篇是「π 家族 RL 支线的深挖」；调研篇是「全行业 RL 地图」——两篇互链，表格在辐射章节有浓缩版。
